# 历史脚本归档

本目录保存「番小绯的国风脚本」在整合为自适应版之前的历史文件，便于回溯、比对与问题排查。

| 文件 | 用途 | 状态 |
|---|---|---|
| `ShanHaiXing-Original.js` | 原始山海行覆写脚本 | 归档，不作为推荐导入入口 |
| `ShanHaiXing-Compat.js` | 缺失地区节点的兼容测试脚本 | 归档，不作为推荐导入入口 |
| `tests/` | 对应历史测试夹具 | 归档，用于回归比对 |

当前唯一推荐导入文件为仓库根目录的 `ShanHaiXing-Adaptive.js`。它保留原版的分流能力，并根据订阅中实际生成的地区组动态构建业务策略候选，避免引用不存在的策略组。
